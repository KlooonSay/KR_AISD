# КР по «Алгоритмам и структурам данных» — вариант 15

Проект содержит две части:

- `cpp/` — реализация всех 17 заданий на C++17. Можно открыть папку как CMake-проект в CLion.
- `macOS/` — отдельная нативная демонстрационная оболочка на SwiftUI в стиле обычного macOS-приложения.

## C++ / CLion

Открыть папку `cpp` в CLion и собрать цель `aisd_kr_v15`.

Из терминала:

```bash
cd cpp
cmake -S . -B build
cmake --build build
./build/aisd_kr_v15
```

После запуска вводится номер задачи `1..17`.

## macOS-приложение

Требования: macOS 13+ и Apple Command Line Tools / Xcode Command Line Tools.

В корне проекта выполнить:

```bash
chmod +x build.command
./build.command
```

Появится:

```text
КР АиСД.app
```

Запуск:

```bash
open "КР АиСД.app"
```

Интерфейс: список 17 задач слева; справа условие, ввод данных, кнопка выполнения и результат. Логика демонстрационного приложения повторяет C++-решения.

## Ввод данных

- Массивы: числа через пробел или запятую.
- Комплексное число: `1+2i`, `2-i`, `3`.
- Матрица: одна строка матрицы на одной строке текста; элементы через пробел. Пример:

```text
1 2
3 4
```

- Для задачи 13 C++-версия принимает путь к исходному текстовому файлу и создаёт `task13_result.txt`. В macOS-оболочке текст можно вставить напрямую.

## Проверка

C++-часть собрана и прогнана на тестовых данных под `g++` с C++17. `TaskEngine.swift` отдельно прошёл typecheck и тесты вычислительной логики. Полную `.app` необходимо собирать именно на macOS, поскольку SwiftUI/AppKit относятся к Apple SDK.

Полный перечень формулировок — в `TASKS.md`.

## Версия интерфейса 1.1

- Главное окно переведено на адаптивную компоновку `NavigationSplitView` без ограничения основной области по ширине.
- Начальный размер окна: 1180×760, минимальный размер содержимого: 760×560.
- Боковая панель: 190–275 pt, рекомендуемая ширина 225 pt.
- Для задач с вводом предусмотрены два простых проверочных набора. Первый набор подставляется автоматически при выборе задачи; второй выбирается кнопкой.
- Кнопка «Очистить» позволяет быстро перейти к ручному вводу.
- Проверочные примеры специально подобраны небольшими и легко проверяемыми вручную.
